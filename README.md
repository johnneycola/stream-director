# Stream Director

Модуль для Foundry VTT v13, позволяющий вести трансляцию с независимыми камерами.

---

## Установка

1. Скопируйте папку `stream-director` в `Data/modules/` вашего Foundry.
2. Активируйте модуль в настройках игры.

---

## Роли

| Роль | Поведение камеры |
|------|-----------------|
| **Мастер** | Полностью свободная камера. Движение токенов и другие события не двигают камеру. Может отправлять камеру оператора в нужную точку. |
| **Игрок** | Своя независимая камера. Движения токенов не двигают её насильно. |
| **Оператор** | Камера автоматически следит за последним подвинутым токеном. Реагирует на «прыжки» от мастера. |

---

## Настройки

### Клиентские (каждый игрок настраивает у себя)

| Параметр | Описание |
|----------|----------|
| **Роль в трансляции** | `gm` / `player` / `operator` |

### Мировые (мастер настраивает в настройках модуля)

| Параметр | Описание |
|----------|----------|
| **ID пользователя-оператора** | Если указан, клиент с этим User ID всегда получает роль оператора независимо от клиентской настройки. Найти ID: меню пользователей → правая кнопка → скопировать ID. |
| **Режим отслеживания** | `any` — любой токен; `players` — только токены игроков; `combat` — активный в Combat Tracker. |
| **Кнопка прыжка камеры** | `middle` — колёсико мыши; `right` — Alt + правая кнопка. |

---

## Как работает прыжок камеры

1. Мастер наводит курсор на любую точку карты.
2. Нажимает **колёсико мыши** (или **Alt + правая кнопка** — зависит от настройки).
3. На экране мастера появляется кратковременный фиолетовый индикатор.
4. Экран оператора плавно перемещается к этой точке.
5. Автоматическое слежение за токеном у оператора при этом отключается до следующего движения токена.

---

## Панель оператора

В правом нижнем углу экрана оператора отображается небольшая панель:

- **Tracking On/Off** — статус автоматического слежения
- **Token** — имя последнего отслеживаемого токена
- Кнопка включения/выключения слежения

---

## Технические детали

- Используется `canvas.animatePan` wrapper — мы оборачиваем родной метод, чтобы блокировать нежелательные панорамирования у мастера и игроков.
- Связь GM → Оператор осуществляется через Foundry socket (`module.stream-director`).
- Модуль не вмешивается в данные сцены или токенов — только в отображение.
